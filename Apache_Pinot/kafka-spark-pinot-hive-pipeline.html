    🏗️ Architecture Explanation

    Apache Kafka

    Role: Ingestion / Event Streaming

    Kafka receives continuous events from applications and provides a scalable, durable buffer between producers and downstream consumers. It stores events in partitioned topics for fault-tolerant, ordered delivery.

    Apache Spark

    Role: Data Processing

    Spark consumes Kafka events using Structured Streaming, cleans the data, validates records, performs transformations, removes duplicates, and creates aggregations for downstream systems.

    Apache Pinot

    Role: Real-Time Analytics

    Pinot stores fresh streaming data and provides very low-latency analytical queries for dashboards and operational analytics. It uses segment-based storage with columnar indexing for sub-second query performance.

    Apache Hive

    Role: Batch / Historical Analytics

    Hive provides SQL-based analytics over large historical datasets stored in the data lake. It uses partition-based storage for efficient scanning of time-ranged queries over petabyte-scale data.
